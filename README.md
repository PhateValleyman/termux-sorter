# Termux Sorter

Automatické třídění souborů pomocí Android Share/Open-With intentů.

## Vylepšení aplikovaná patchem
- bezpečnější přesuny
- ochrana proti kolizím názvů
- lepší error handling
- Material/AppCompat závislosti

## Build

```bash
pkg install openjdk-17 gradle
gradle assembleRelease
```
